    Para ler com cuidado

    O que este índice não é

    • Não é o IPCA do bairro. O IBGE não publica IPCA por bairro. Este é um índice do projeto, com a cesta do projeto.
    • Cada produto pesa igual. Os pesos do IPCA ainda não foram preenchidos. Quando entrarem, o índice muda.
    • Carnes, frutas e verduras ficam fora. Cortes e qualidade variam entre lojas, e a comparação deixaria de ser do mesmo produto.
    • O perfil é uma classificação do projeto. Central, Intermediário e Periferia não são dados oficiais. A ideia é trocar por dados de renda.
    • Só a capital, em 25 pontos. Um ponto representa os distritos em volta. Dois vizinhos podem pagar preços diferentes.
    • É o preço do site das redes. O site consulta o preço que cada rede mostra na internet para o CEP. A prateleira pode ter outro preço.
